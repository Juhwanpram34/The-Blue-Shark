# 🦈 The Blue Shark — AI Multi-Agent Platform

> Predator Edition — Platform AI Multi-Agent untuk bisnis yang serius.

## Fitur

- 🔍 **Market Research Agent** — Riset pasar & analisis kompetitor
- ✍️ **Content Creator Agent** — Pembuatan konten & copywriting
- 📊 **Sentiment Analysis Agent** — Analisis sentimen & brand monitoring
- 🚀 **Marketing Optimizer Agent** — Optimasi pemasaran & growth hacking
- 🛡️ **Cybersecurity Agent** — Keamanan siber & perlindungan data
- ⚙️ **Workflow Automation Agent** — Otomatisasi alur kerja
- 🧠 **ML Performance Agent** — Machine learning & optimasi AI
- 💬 **Customer Support Agent** — Dukungan pelanggan & chatbot design

## Tech Stack

- **Frontend:** Next.js 15, React 19
- **Backend:** Next.js API Routes
- **Database:** Supabase (PostgreSQL)
- **Auth:** Supabase Auth
- **AI:** OpenAI GPT-4
- **Hosting:** Vercel

## Setup

1. Clone repo
2. `npm install`
3. Copy `.env.local.example` ke `.env.local` dan isi credentials
4. `npm run dev`
